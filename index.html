HOW IT WORKS

Built for traceability, not blind automation.

CivilStandards indexes official jurisdictional sources and records when each source was last checked. A scheduled monitor creates a new version when source content changes and flags that event for human review.

1

Index

Store jurisdiction, agency, discipline, detail number, revision label, and official source URL.

2

Monitor

Fetch official sources on a schedule and compare normalized content hashes.

3

Review

Changed sources are marked “Needs review” instead of silently becoming approved design guidance.
